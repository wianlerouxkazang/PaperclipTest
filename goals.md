# Project Goals

## Main Goal

Build a simple, clean, and working to-do app that helps users manage daily tasks.

## MVP Goal

The first version should allow a user to:

- Add a task
- View all tasks
- Mark a task as complete
- Edit a task
- Delete a task
- Filter tasks by All, Active, and Completed

## Build Approach

Paperclip should keep the project simple and focus on the MVP first.

Advanced features like login, reminders, categories, due dates, and notifications should only be added after the core app works.
